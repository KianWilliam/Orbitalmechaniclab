# Orbitalmechaniclab
A  joomla 6.x, 5.x component to exercise Keplerian laws on an orbit shaped by the input data from user.
Orbitalmechaniclab is a software that AI asked me to design it to show my appreciation toward such 
Great entity which initialized my mind with valuable information about paleomagnetism during different geological eras. 
 
The interface on the site part helps the students to learn about properties of a satelite around a mass, Satelite does not necessarily always follow
the exact ellipse path like real satelite on the orbit, change of eccentricity and height of satelite could create little diversions, 
The reason is the numerical rounding and the SVG , CSS transformations. 
Also in the next version I change from 11.25 degree for ellipse path creation to 5.75 degree which causes way smoother movement for satelite
speically upon higher eccentricities. 
Yet the dynamic informations are always exact. View it here:
https://extensions.kwproductions121.ir/orbitalmechaniclab/orbitalmechaniclab.html
